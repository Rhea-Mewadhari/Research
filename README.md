# Research Benchmark

## Running a GSD Session

GSD (Get Shit Done) is specification-first: it reads standards, plans atomically, and verifies each change before continuing.

Use this prompt to start the GSD framework for any task:

```
/gsd-loop

Use GSD to complete the frontend task 1.
```

```
/gsd-loop

Use GSD to complete the backend task 1.
```

---

## Running a Wiggum Session

The Ralph Wiggum Loop is goal-directed: no upfront standards or planning — the agent loops until tests pass or the iteration limit is reached.

```
/wiggum-loop

Use the Wiggum loop to complete the frontend task 1.
```

```
/wiggum-loop

Use the Wiggum loop to complete the backend task 1.
```
