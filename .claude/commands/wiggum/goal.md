# Orient — Understand the Goal

Before looping, establish what "done" looks like.

---

## Read the task

Task instructions are at:

```
benchmark-frontend/instructions/
benchmark-backend/instructions/
```

Read every file in the instructions directory for your target.

---

## Define done

Done means:

- The visible tests pass: `benchmark-frontend/tests/` or `benchmark-backend/src/tests/visible/`
- The build passes
- The task requirements described in the instructions are satisfied

You do not need to produce a plan or a structured summary. Understand enough to make the first change.

---
