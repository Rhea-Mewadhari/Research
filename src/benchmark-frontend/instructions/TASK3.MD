# Task 3: Frontend Syntax Bug Fix

## Objective

The application currently contains syntax and runtime errors that prevent it from compiling or running correctly.

Your task is to fix these issues so that:
- the application builds successfully
- the UI renders correctly
- all tests pass

---

## Context

The codebase includes:
- React components
- TypeScript types
- filtering utilities

Some files contain:
- invalid JSX
- incorrect TypeScript usage
- broken event handlers
- improper imports/exports

---

## Requirements

Fix all syntax and runtime errors, including:

### 1. JSX issues
- Invalid element structure
- Missing closing tags
- Incorrect attributes

### 2. TypeScript issues
- Incorrect types
- missing or incompatible type usage
- improper function signatures

### 3. Event handling
- Broken or missing handlers
- incorrect parameter usage

### 4. Imports/exports
- invalid imports
- incorrect default vs named exports

---

## Constraints

- Do not change functionality beyond fixing errors
- Do not rewrite components unnecessarily
- Keep behavior consistent with intended feature

---

## Expected Files to Modify

Any file with syntax or runtime errors

---

## Success Criteria

- App builds without errors
- Tests run successfully
- No runtime crashes in the browser
